The new [OpenBabel book](http://baoilleach.blogspot.com/2011/03/open-babel-book-now-available.html)
acknowledges the contributors to the project (deduced from [Jörg's thanx](http://friendfeed.com/joergkurtwegner/0bf202dc/just-ordered-openbabel-book-and-i-love-open)).
My [Groovy Cheminformatics](http://chem-bla-ics.blogspot.com/2011/02/groovy-cheminformatics.html)
book is about using the [CDK](http://cdk.sf.net/), not about the project itself
really, but shows many similarities to the [OpenBabel](http://openbabel.org/)
book. [Edition 1.3.8-0](http://www.lulu.com/author/content_revise.php?fCID=10148132)
of my book does not contain a list of contributors to the CDK library. This
is being fixed now.

In one go I also updated the [AUTHORS](https://github.com/cdk/cdk/blob/cdk-1.4.x/AUTHORS)
list distributed with the source code. The list of individuals who have contributed
source code to the project has grown to 64! Here are a few of the new names:
