Just a quick forward. Roman posted this announcement for tutorials around the
Open [OpenTox](http://www.opentox.org) Standard:

> The first tutorial will be held Wednesday, 30 March, at 15:00 CET, and aiming at Java developers who want to learn
> how to build an OpenTox API compliant Web service (some acquaintance with [Restlet](http://www.restlet.org/), and
> basic knowledge of the [OpenTox REST API](http://opentox.org/dev/apis/api-1.2), is necessary). Participation in
> these online events involves no registration fee. For more information, as well as to register, visit
> [www.opentox.org/meet/opentoxonline](http://www.opentox.org/meet/opentoxonline).
